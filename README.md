# Shreya Savant - Portfolio Website

[![Website Status](https://img.shields.io/website?url=https%3A%2F%2Fshreyasavant.github.io)](https://shreyasavant.github.io)
[![GitHub Pages](https://img.shields.io/badge/Hosted%20on-GitHub%20Pages-blue)](https://pages.github.com/)

Personal portfolio website showcasing my work as an AI researcher and systems engineer. Built with a focus on performance, accessibility, and a GitHub-inspired aesthetic.

## 🌐 Live Site
**[shreyasavant.github.io](https://shreyasavant.github.io)**

## ✨ Features

- **GitHub-Inspired UI**: Clean, minimal design following GitHub's aesthetic
- **Dark/Light Theme**: Persistent theme toggle with localStorage
- **Dynamic GitHub Integration**: Real-time profile data and repository showcase
- **GitHub Contribution Graph**: Visual activity calendar
- **Responsive Design**: Mobile-first approach with smooth animations
- **Image Gallery**: Masonry layout with shuffle on load
- **Performance Optimized**: Lazy loading, efficient CSS, minimal JavaScript

## 🛠️ Tech Stack

- **HTML5**: Semantic markup
- **CSS3**: Custom properties, Grid, Flexbox, Animations
- **JavaScript (ES6+)**: Modular, vanilla JS (no frameworks)
- **GitHub API**: Dynamic data fetching
- **GitHub Pages**: Static site hosting

## 🎨 Key JavaScript Features

- **Fisher-Yates Shuffle**: Gallery randomization on page load
- **Intersection Observer**: Scroll-triggered reveal animations
- **Theme Management**: Light/dark mode with localStorage persistence
- **GitHub API Integration**: Profile stats and repository cards
- **Smooth Scrolling**: Enhanced navigation experience
- **Form Enhancement**: Contact form with visual feedback

## 🚀 Quick Start

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/shreyasavant/shreyasavant.github.io.git
cd shreyasavant.github.io
```

2. Serve locally with Python:
```bash
python3 -m http.server 8000
```

3. Open `http://localhost:8000` in your browser

### Deployment

Automatically deployed via GitHub Pages from the `main` branch.
